# thought-sprout frontend

React app built with [Vite](https://vite.dev).

## Scripts

- `npm start`: dev server at http://localhost:3000. API requests are proxied to the backend on http://localhost:3001 (see `vite.config.js`), so start the backend first.
- `npm run build`: production build into `dist/`.
- `npm run preview`: serve the production build locally.
- `npm test`: run tests with Vitest.
